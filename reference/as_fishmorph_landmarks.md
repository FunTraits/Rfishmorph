# Coerce to fishmorph_landmarks

Coerce to fishmorph_landmarks

## Usage

``` r
as_fishmorph_landmarks(x, ...)
```

## Arguments

- x:

  A `fishmorph_landmarks`, `intrait_landmarks`, matrix, array or data
  frame.

- ...:

  Passed to
  [`fishmorph_landmarks()`](https://funtraits.github.io/Rfishmorph/reference/fishmorph_landmarks.md).

## Value

A `fishmorph_landmarks` object.
