# Look up the species colours used by the ordination plots

Look up the species colours used by the ordination plots

## Usage

``` r
group_colors(x)
```

## Arguments

- x:

  An object with a `$groups` element, or a factor/character vector of
  group labels.

## Value

A data frame with columns `group` and `color`.
