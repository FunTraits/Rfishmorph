# History of the records of one key

Useful to check that a correction was taken into account, or to compare
two passes over the same specimen.

## Usage

``` r
fm_journal_history(journal_dir, row_key = NULL)
```

## Arguments

- journal_dir:

  Journal directory, or an already-read data.frame.

- row_key:

  Key to inspect. NULL -\> summary of every key.
